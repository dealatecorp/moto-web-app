# PROFIT+ Auto Finance

A small browser based auto finance management prototype inspired by the uploaded desktop application screenshots.

## Open the application

Open `index.html` in a modern browser. No install step or server is required.

## Included workflows

- Dashboard with a portfolio overview and quick module shortcuts
- Finance account opening with customer, guarantor, vehicle, and installment details
- Customer and HP account registers
- Receipt entry with generated receipt numbers and account balance updates
- Installment due list, customer ledger, HP register, daybook, and monthly transaction views
- Vehicle seizure and release status updates
- Account closing checks and CSV exports

The prototype stores entries in this browser's `localStorage`. The preloaded account data is fictional sample data. It does not connect to a finance database, printer service, payment gateway, or external accounting system.
